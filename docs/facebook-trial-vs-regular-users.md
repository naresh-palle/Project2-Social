# Facebook / Instagram: public login

Product decision: **every Facebook user** (and Instagram Professional accounts) should be able to Sign In — no “use my Facebook / tester only” flow.

See **`docs/meta-public-login.md`** for the Meta **Live** toggle and Render `META_OAUTH_MODE=business`.

While the Meta app remains in **Development**, Meta itself will still block non–app-role accounts no matter what flugr shows. That block is removed only when the app is **Live**.
